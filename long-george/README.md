# LONG George

![LONG George animated preview](./preview.gif)

George is an observant, affectionate black-and-white girl with amber eyes, wonderfully long legs and body, a long white neck patch, a distinctive crown spot and one slightly softer, floppier white-marked ear.

She supervises work with gentle seriousness and impeccable deadpan timing.

This character is based on Lacey Dandy's real family dog. The result has more personal meaning than the two fan-inspired experiments in this collection because each small marking and proportion belongs to George.

## Files

- `spritesheet.png` is the complete validated Pets v2 artwork.
- `preview.gif` cycles through all standard work states.
- `look-loop.gif` shows the directional look loop.
- `pet-info.json` records the layout and checksum.
- `INSTALL.md` contains a ready-to-paste import request.
