# Inspired by Peach Monster Can

![Peach can inspired pet animated preview](./preview.gif)

A blue-eyed peach energy-can creature with light limbs, floral linework and fizzy confidence.

This is an unofficial, non-commercial fan creation. It is not endorsed by or affiliated with any beverage company or brand owner. No official logo or copied packaging artwork is included.

## Files

- `spritesheet.png` is the complete validated Pets v2 artwork.
- `preview.gif` cycles through all standard work states.
- `look-loop.gif` shows the directional look loop.
- `pet-info.json` records the layout and checksum.
- `INSTALL.md` contains a ready-to-paste import request.
